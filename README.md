# 🌍 Explore - Travel Website

A modern, responsive travel website built using **HTML, CSS, JavaScript, and Bootstrap 5**. The website provides an attractive travel-focused interface with a responsive navigation bar, hero carousel, feature section, image gallery, destination cards, and footer.

## ✨ Features

* 📱 Fully responsive design
* 🧭 Responsive Bootstrap navigation bar
* 🖼️ Bootstrap hero carousel with multiple slides
* 🔎 Search functionality
* 🗺️ Travel features section using Flexbox
* 📸 Responsive 3 × 3 CSS Grid photo gallery
* 🏔️ Bootstrap destination cards
* 🎨 Hover animations and smooth transitions
* 🔝 Back-to-top button
* 📱 Mobile-friendly layout
* ♿ Accessibility-friendly structure with `alt` text and ARIA attributes
* 🦶 Responsive footer with useful links and social media icons

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Custom styling, Flexbox, CSS Grid, animations
* **JavaScript** – Search and interactive functionality
* **Bootstrap 5** – Responsive layout and UI components
* **Bootstrap Icons** – Icons used throughout the website
* **Unsplash** – Travel images

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

CSS media queries are used to adjust the navigation, gallery, cards, typography, and layout for smaller screens.

### Navigation Bar

The responsive navbar contains:

* Website logo/brand
* Home
* Features
* Gallery
* Destinations
* Contact
* Search bar
* Mobile hamburger menu

### Hero Carousel

The Bootstrap carousel contains multiple travel images with:

* Captions

Three main travel features are displayed using a Flexbox layout:

1. **Explore** – Discover new places and experiences.

## 🌐 Deployment

This project can be deployed easily using **GitHub Pages**.

### Deploy using GitHub Pages

1. Push the project to GitHub.
2. Open the repository on GitHub.
3. Go to **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
6. Click **Save**.
7. GitHub will generate a live website URL.

Your website will be available at:

```text
https://your-username.github.io/travel-project/
```
